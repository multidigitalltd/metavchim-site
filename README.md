# מתווכים. — אתר שיווקי (WordPress)

תבנית וורדפרס ייעודית המשחזרת 1:1 את עיצוב ה-Handoff של האתר השיווקי של **מתווכים.** — מערכת SaaS למשרדי תיווך וסוכנים עצמאיים. פותחה לפי תקן הפיתוח של Multi Digital: מהירה, רזה, מאובטחת ונגישה.

## מבנה

```
wp-content/themes/metavchim/
├── style.css              # הצהרת התבנית בלבד (ללא CSS בפועל — חוסך בקשת HTTP)
├── functions.php          # טעינת רכיבי inc
├── inc/
│   ├── setup.php          # theme supports, תפריטים, ניקוי head, כיבוי אמוג'י/XML-RPC
│   ├── assets.php         # טעינת נכסים מותנית, defer, preload פונטים, הסרת block-library
│   ├── template-tags.php  # לוגו inline, פולבאקים לתפריטים, סרגל נגישות
│   ├── seo.php            # OG + Schema — רק כשאין תוסף SEO פעיל
│   └── install-content.php# מתקין תוכן חד-פעמי בהפעלת התבנית
├── patterns/              # 10 סקשני עמוד הבית + עמוד רשת המשרדים — Block Patterns
├── assets/
│   ├── css/ main.css (כל האתר) · home.css (בית) · collab.css (רשת המשרדים)
│   ├── js/  main.js (ניווט, reveal, סרגל נגישות) · home.js (טאבים)
│   ├── fonts/ Almoni ×4 משקלים (woff, font-display: swap)
│   └── img/ לוגואים + favicon
└── header/footer/front-page/page/page-collaboration/index/404.php
```

## התוכן הוא תוכן עמודים אמיתי

בהפעלת התבנית (`after_switch_theme`) רץ מתקין חד-פעמי שיוצר:

- **עמוד "בית"** — כל 10 הסקשנים נשמרים כבלוקים ב-`post_content` של העמוד עצמו, והעמוד מוגדר כעמוד הבית הסטטי. התוכן ניתן לעריכה מלאה בעורך הבלוקים — לא HTML קשיח שמולבש על הכתובת מתוך קבצי התבנית.
- **עמוד "רשת המשרדים"** (`/collaboration/`) — עמוד פנימי מלא על רשת שיתופי הפעולה, גם הוא כתוכן עמוד ניתן לעריכה. מוצג דרך `page-collaboration.php` ברוחב מלא, וה-CSS שלו (`collab.css`) נטען רק בעמוד הזה.
- **עמודים משפטיים** — תנאי שימוש, פרטיות והצהרת נגישות (שלד לפי ת"י 5568 — יש להשלים פרטי רכז נגישות).
- **תפריטים** — ראשי (עוגני הסקשנים + רשת המשרדים) ופוטר (העמודים המשפטיים).

בנוסף, כל סקשן רשום כ-Block Pattern בקטגוריית "מתווכים — סקשנים", כך שאפשר להוסיף אותו מחדש לכל עמוד. אם המתקין לא רץ עדיין, `front-page.php` מרנדר את הסקשנים ישירות מהקבצים — האתר נראה זהה בכל מקרה.

## ביצועים

- אפס ספריות צד ג', אפס jQuery — Vanilla JS בלבד (‎~6KB JS סה"כ).
- טעינה מותנית: `home.css`/`home.js` נטענים רק בעמוד הבית.
- כל ה-JS נטען עם `defer`; פונטים קריטיים (400, 900) ב-preload.
- הוסרו: emoji scripts, block-library CSS, global-styles, generator tag ועוד.
- כל האנימציות ב-CSS בלבד (transform/opacity — ידידותי ל-compositor).
- אין קריאות API, אין שאילתות DB מעבר לליבת וורדפרס; אופציית המתקין נשמרת ללא autoload.
- תואם LiteSpeed Cache / WP Rocket / Redis / Cloudflare (אין inline state, אין nonce בעמודים ציבוריים).

## נגישות (ת"י 5568 / WCAG 2.2 AA)

- HTML סמנטי, H1 יחיד, היררכיית כותרות תקינה, skip-link, מצבי פוקוס ברורים.
- טאבים נגישים (role=tablist, חיצים, Home/End), תפריט מובייל עם aria-expanded ו-Esc.
- `prefers-reduced-motion` מכבה את כל האנימציות והלולאות.
- סרגל נגישות מובנה: הגדלת/הקטנת טקסט, ניגודיות, היפוך צבעים, גווני אפור, הדגשת קישורים, פונט קריא, עצירת אנימציות, הבלטת כותרות/קישורים וסרגל קריאה — נשמר ב-localStorage.
- עמוד הצהרת נגישות נוצר אוטומטית.

## התקנה

1. להעלות את `wp-content/themes/metavchim` לאתר (או לארוז כ-zip: `cd wp-content/themes && zip -r metavchim.zip metavchim`).
2. להגדיר את שפת האתר לעברית (הגדרות ← כללי) כדי לקבל `dir="rtl"` מלא גם באדמין.
3. להפעיל את התבנית — התוכן, העמודים והתפריטים נוצרים אוטומטית.
4. להשלים: פרטי רכז נגישות בעמוד ההצהרה, נוסח משפטי לתנאים/פרטיות, ויעד אמיתי לכפתורי ההדגמה (כרגע עוגן `#cta`).

## דרישות

WordPress 6.4+ · PHP 8.1+ (תואם 8.3)
